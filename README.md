# Starry-Sky 项目运行步骤
## 一、项目克隆与运行步骤
### 1. 环境准备
- 安装 Node.js（建议 LTS 版本，兼容项目依赖即可）；
- 安装 Git（用于克隆代码库）；
- 包管理器：npm（Node.js 自带）/ yarn / pnpm（任选其一）。

### 2. 代码克隆
| 步骤 | 操作命令 | 说明 |
|------|----------|------|
| 1 | `git clone <项目仓库地址>` | 克隆代码库到本地 |
| 2 | `cd Starry-Sky` | 进入克隆后的项目根目录 |

### 3. 核心运行命令
| 步骤 | 操作命令 | 说明 |
|------|----------|------|
| 1 | `npm install` | 安装项目依赖（Vue、Vue Router、Vite、ESLint、Prettier 等） |
| 2 | `npm run dev` | 启动开发环境，默认访问地址：`http://localhost:5173/`（热更新生效） |
| 3 | `npm run lint` | 自动修复 ESLint 规范 + Prettier 格式问题 |

## 二、项目简介
Starry-Sky 是基于 Vue 3 + Vite 构建的轻量级前端星空探索类单页应用，聚焦沉浸式星空视觉体验与基础路由交互.

### 1. 核心技术栈
| 类别 | 技术/工具 | 核心作用 |
|------|-----------|----------|
| 核心框架 | Vue 3（组合式 API/`<script setup>`） | 组件化开发，简化逻辑编写 |
| 路由管理 | Vue Router 4.x | 实现页面路由跳转（启动页 → 首页） |
| 构建工具 | Vite 7.x | 极速冷启动、热模块替换（HMR），支持生产打包/本地预览 |
| 代码规范 | ESLint + Prettier | 代码质量校验 + 统一格式化，保证代码风格一致 |
| 样式方案 | CSS3 + Vue Scoped Style | 原生 CSS3 实现渐变、动画、响应式；<br>Vue 单文件组件 `scoped` 样式隔离，避免样式污染 |

### 2. 工程化配置
#### （1）Prettier 格式化规范
| 配置项 | 取值 | 规则含义 |
|--------|------|----------|
| `printWidth` | `80` | 单行代码最大字符数，超过自动换行 |
| `tabWidth` | `2` | 缩进空格数为 2 个（符合前端主流规范） |
| `useTabs` | `false` | 禁用制表符，统一使用空格缩进 |
| `semi` | `true` | 语句末尾强制加分号 |
| `singleQuote` | `true` | 字符串强制使用单引号 |
| `endOfLine` | `crlf` | 适配 Windows 换行符 |
| `proseWrap` | `"preserve"` | Markdown 文件保留原有换行 |
| `htmlWhitespaceSensitivity` | `"ignore"` | HTML/Vue 模板空格不敏感 |
| `vueIndentScriptAndStyle` | `true` | Vue 文件脚本/样式跟随外层缩进 |
- 生效范围：`.js`/`.mjs`/`.cjs`、`.vue`、`.md`、`.html` 文件；
- 忽略范围：根目录 `.prettierignore` 指定无需格式化的文件/目录。

### （2）ESLint 代码校验规范
- 核心配置文件：根目录 `eslint.config.js`
- 核心规则：
  - 禁用 debugger、限制 console（仅允许 warn/error）；
  - 强制驼峰命名、禁止未使用变量、禁止 var 声明；
  - Vue 组件强制声明 props 类型、规范组件选项顺序；
  - 禁用与 Prettier 冲突的缩进/引号/连字符等规则，将 Prettier 格式问题作为 ESLint 错误提示；
- 忽略范围：`dist/`、`node_modules/`、`public/`、`vite.config.js` 等目录/文件。

### 3. 核心功能与视觉设计
#### （1）启动页模块（Start.vue）
作为应用入口核心页面，包含以下子功能：
- 视觉层：多层级星空背景（静态背景图 + 动态粒子闪烁动效），叠加渐变遮罩提升层次感；
- 交互层：「开始探索」核心按钮（带流光、hover、点击反馈动效），点击触发路由跳转至 `/home`；
- 动效层：页面加载时内容渐入 + 上移动画，星星元素循环闪烁动画，提升页面生动性；
- 文案层：渐变文字标题（星空主题文案），搭配自定义太空风格字体（Orbitron）强化主题。

#### （2）首页模块（Home.vue）
作为路由跳转目标页面，核心设计：
- 基础布局：延续星空主题风格，适配启动页视觉一致性；
- 功能占位：预留核心功能扩展入口（如星空图鉴、星座查询等）；
- 导航层：支持返回启动页的按钮，完善路由闭环。

### 4. 视觉与交互设计亮点
- 主题化视觉：全页面围绕「星空」主题，使用深蓝/黑色系主色调，搭配白色/浅蓝渐变，模拟宇宙视觉效果；
- 动态交互：
  - 粒子动效：通过 CSS3 径向渐变 + 动画，模拟星星随机闪烁效果；
  - 按钮动效：线性渐变背景 + 流光动画，hover 时放大、点击时缩小的反馈；
  - 页面过渡：路由跳转时添加淡入淡出过渡动画，提升页面切换体验；
- 字体定制：引入开源太空风格字体 Orbitron，替换系统默认字体，强化主题沉浸感；
- 分层设计：通过 `z-index` 分层管理背景、遮罩、内容、交互元素，避免视觉层级混乱。
